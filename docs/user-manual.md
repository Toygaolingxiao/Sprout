# Sprout 利用マニュアル

最終更新: 2026-04-30
対象: エンドユーザー（妊活・妊娠・産後・育児のタスク共有）

## 1. できること

- 妊活・妊娠・産後・育児のチェックリストを管理
- 期限に近いタスクを確認し、完了/未完了を切り替え
- 夫婦/家族で同じタスクを共有（招待・参加・退出）
- 女性向け・男性向け・共通タスクを切り替え
- テンプレート再適用（高/中/低）と手動追加項目の一括整理
- Google/LINE の連携状態を確認し、設定画面から連携管理
- 設定画面でプロフィール・日程・外観・言語を一元管理
- 更新履歴（簡略）を設定画面から確認

## 2. はじめる前に

- PC またはスマートフォンのブラウザ
- インターネット接続
- メールアドレス、Google アカウント、または LINE アカウント

補足:
- Google / LINE ログイン時、Sprout が各サービスのパスワードを保存することはありません。

## 3. 新規登録とログイン

### 3.1 メールで登録

1. サインアップ画面を開く
2. ニックネーム、メールアドレス、パスワード（8文字以上）を入力
3. 「アカウント作成」を押す
4. ダッシュボードに遷移したら登録完了

### 3.2 Google / LINE で登録・ログイン

1. ログインまたはサインアップ画面で「Googleでログイン/登録」または「LINEでログイン/登録」を押す
2. 各サービスの認証を完了する
3. ダッシュボードに遷移したら完了

補足:
- LINE ログインは環境設定不備（Provider名、Redirect URL、OIDC設定など）があると失敗することがあります。
- 失敗時は画面のエラーメッセージに沿って設定を見直してください。

## 4. 初期設定（設定画面）

1. 設定画面を開く
2. 「プロフィールと日程」セクションで以下を入力
3. 「保存」を押す

入力項目:
- ライフステージ
- 妊娠予定時期（妊活フェーズ向け）
- 出産予定日（妊娠以降のフェーズ向け）
- 赤ちゃんの性別
- あなたの性別

## 5. 家族共有（2アカウント接続）

### 5.1 共有の仕組み

- 1人目のアカウントは家族グループのオーナーになります
- オーナーのみ招待リンクを作成できます
- 招待リンクの有効期限は7日です

### 5.2 接続手順

1. 1人目が「家族」画面を開く
2. 「招待リンクを生成」を押す
3. 表示されたリンクをコピーして2人目に共有
4. 2人目が別アカウントでログイン
5. 2人目が招待リンクを開き「家族グループに参加」を押す
6. 2人とも同じ家族メンバー一覧に表示されれば完了

### 5.3 家族グループから退出

1. 「家族」画面の退出セクションを開く
2. 確認文字列 `LEAVE` を入力
3. 「退出を実行」を押す

補足:
- 最後のメンバーが退出した場合、家族グループは自動削除されます。

## 6. チェックリストの使い方

### 6.1 ステージを選ぶ

1. 「チェックリスト」で対象ステージを開く
2. 上部タブで他ステージにも切り替え可能

### 6.2 タスクを完了する

- タスク左のチェックを押すと完了
- もう一度押すと未完了に戻る

### 6.3 タスク詳細を確認する

- 「要点・注意事項を見る」を押して詳細表示
- URL が含まれる場合はリンクとして開けます

### 6.4 フィルター

- カテゴリ（手続き/買い物/健康/財務/その他）で絞り込み
- 性別（すべて/女性向け/男性向け）で絞り込み

### 6.5 テンプレート管理

1. 設定画面の「テンプレート」セクションを開く
2. 再適用したい優先度（高/中/低）を選択
3. 「テンプレ再適用」を押す

補足:
- 再適用はデフォルト項目のみを対象にし、手動追加項目は保持されます。

### 6.6 手動追加項目の一括削除

- 「このステージの手動項目を削除」: 現在のステージのみ削除
- 「全ステージの手動項目を削除」: 全ステージの手動追加項目を削除

## 7. 設定画面の各セクション

- プロフィールと日程: 基本情報と基準日を編集
- 表示: 言語とテーマ切替
- テンプレート: 再適用と一括削除
- アプリ情報: バージョン、マニュアル、簡略更新履歴
- アカウント: Google/LINE 連携、メール変更、パスワード変更、ログアウト
- 注意操作: アカウント削除（確認文字列 `DELETE` が必要）

## 8. 言語切り替え

1. 設定画面を開く
2. 言語で「日本語」または「中文（简体）」を選択
3. 画面文言が即時反映される

補足:
- 一部の詳細文が未翻訳の場合、中国語画面では中国語の補完メッセージを表示します。

## 9. よくあるトラブル

### 9.1 招待リンクが使えない

- 7日を過ぎていないか確認
- すでに使用済みでないか確認
- オーナーに再発行してもらう

### 9.2 Google / LINE ログインが失敗する

- 時間をおいて再試行
- ブラウザで Cookie が有効か確認
- 設定不備が示されるメッセージ（Provider名、Redirect URL など）に沿って修正

### 9.3 タスクが表示されない

- ステージ選択が正しいか確認
- 「テンプレ再適用」でデフォルト項目を復元
- 画面を再読み込み

## 10. セキュリティの基本

- 可能なら Google / LINE ログインを優先
- メール登録時は使い回ししない強いパスワードを使用
- 公共端末では利用後にログアウト
- 招待リンクは信頼できる相手のみに共有
- 退会・削除操作時は確認文字列を必ず確認してから実行
