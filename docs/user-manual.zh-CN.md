# Sprout 使用手册

最后更新: 2026-04-30
适用对象: 终端用户（备孕、怀孕、产后、育儿任务共享）

## 1. 可以做什么

- 管理备孕、怀孕、产后、育儿四个阶段的清单
- 查看临近截止日期的任务并切换完成状态
- 夫妻/家庭共享同一份任务（邀请、加入、退出）
- 按性别筛选任务（女性向、男性向、共通）
- 重新应用模板（高/中/低）并批量整理手动添加任务
- 在设置页管理 Google/LINE 关联状态
- 在设置页统一管理资料、日程、外观、语言
- 在设置页查看简版更新记录

## 2. 开始前准备

- 电脑或手机浏览器
- 可用的网络连接
- 邮箱、Google 账号或 LINE 账号

补充:
- 使用 Google / LINE 登录时，Sprout 不会保存这些服务的密码。

## 3. 注册与登录

### 3.1 邮箱注册

1. 打开注册页面
2. 输入昵称、邮箱、密码（8位以上）
3. 点击“创建账号”
4. 跳转到仪表板后即完成

### 3.2 Google / LINE 注册与登录

1. 在登录或注册页点击“使用 Google 登录/注册”或“使用 LINE 登录/注册”
2. 完成对应平台授权
3. 跳转到仪表板后即完成

补充:
- LINE 登录在 Provider 名称、Redirect URL、OIDC 配置不一致时可能失败。
- 失败时请按页面提示逐项检查配置。

## 4. 初始设置（设置页）

1. 打开设置页
2. 在“资料与日程”中填写信息
3. 点击“保存”

可填写项目:
- 人生阶段
- 预计怀孕时间（备孕阶段）
- 预产期（怀孕阶段及之后）
- 宝宝性别
- 你的性别

## 5. 家庭共享（两个账号连接）

### 5.1 共享机制

- 第一个账号会成为家庭组 owner
- 仅 owner 可以生成邀请链接
- 邀请链接有效期为 7 天

### 5.2 连接步骤

1. 第一个账号进入“家庭”页面
2. 点击“生成邀请链接”
3. 复制链接并发送给第二个账号
4. 第二个账号使用另一个账号登录
5. 打开邀请链接并点击“加入家庭组”
6. 两边都看到同一成员列表即完成

### 5.3 退出家庭组

1. 在“家庭”页面打开退出区域
2. 输入确认字符串 `LEAVE`
3. 点击“执行退出”

补充:
- 若最后一位成员退出，家庭组会自动删除。

## 6. 清单使用方式

### 6.1 选择阶段

1. 在“清单”打开目标阶段
2. 可通过顶部标签切换其他阶段

### 6.2 完成任务

- 点击任务左侧复选框标记完成
- 再次点击可恢复为未完成

### 6.3 查看任务详情

- 点击“查看要点・注意事项”展开详情
- 若文本含 URL，可直接打开链接

### 6.4 筛选

- 按分类筛选（手续/购物/健康/财务/其他）
- 按性别筛选（全部/女性向/男性向）

### 6.5 模板管理

1. 在设置页打开“模板”区域
2. 选择要重新应用的优先级（高/中/低）
3. 点击“应用模板”

补充:
- 重新应用仅影响默认模板项，手动添加项会保留。

### 6.6 批量删除手动任务

- “删本阶段手动项”: 仅删除当前阶段
- “删全部手动项”: 删除全部阶段手动添加项

## 7. 设置页分区说明

- 资料与日程: 编辑基础资料与基准日期
- 显示: 切换语言与主题
- 模板: 重新应用与批量删除
- 应用信息: 版本、手册、简版更新记录
- 账号: Google/LINE 关联、邮箱修改、密码修改、退出登录
- 高风险操作: 删除账号（需输入确认字符串 `DELETE`）

## 8. 语言切换

1. 打开设置页
2. 在语言选择“日本語”或“中文（简体）”
3. 页面文案会即时生效

补充:
- 若部分详情尚未翻译，中文界面会显示中文补充提示。

## 9. 常见问题

### 9.1 邀请链接无法使用

- 确认是否超过 7 天
- 确认是否已被使用
- 请 owner 重新生成链接

### 9.2 Google / LINE 登录失败

- 稍后重试
- 确认浏览器已启用 Cookie
- 按页面提示检查 Provider、Redirect URL 等配置

### 9.3 看不到任务

- 确认当前阶段是否正确
- 使用“应用模板”恢复默认项目
- 刷新页面

## 10. 安全建议

- 建议优先使用 Google / LINE 登录
- 邮箱注册请使用强密码且避免复用
- 在公共设备使用后请退出登录
- 邀请链接仅分享给可信对象
- 执行退出/删除前请确认输入字符串与目标操作一致
