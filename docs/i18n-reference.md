## 注意事項

1. **チェックリスト本文は段階的翻訳対応** — 未翻訳の詳細文は中国語画面で中国語補完メッセージを表示
2. **ステージ名・カテゴリ名はUIラベルとして翻訳対象**
3. 中文は简体中文（中国大陸向け）を採用
4. 敬語・丁寧語は中文では省略（文化的に自然な表現を優先）
5. 「さん」等の敬称は中文では不使用
